# 政策、宏观数据与新闻 API 契约

在首次接入一个私有数据源时，先取得 API 文档或一个脱敏响应样本。不得从密钥、环境变量或猜测中推断端点和字段。

## 新闻

每条新闻至少需要：`id`、`published_at`（含时区）、`source`、`title`、`url`、`summary` 或 `body`、`language`。可选字段包括相关实体、主题、原文链接和可信度标签。保留 URL，以便把市场报道和一手文件分开。

## 宏观数据与日历

每次发布至少需要：指标名称、地区、发布时点、参考期、实际值、前值、修正值、市场预期、单位、季调/年化口径和来源链接。若缺失预期或修正值，报告必须明确缺失，不能自行补造“超预期”。

## 政策文件

至少需要：发布机构、文件类型、发布时间、标题、原文 URL、正文或摘要、适用地区和状态（拟议/已发布/已生效）。保留原文版本，避免把随后修改过的网页当成当时已知信息。

## 使用规则

- API 密钥仅保留在本机安全配置或用户指定的密钥管理器中，不进入 Git、报告或日志。
- 记录拉取时间、数据发布日期及延迟/修订状态。
- API 与原始来源冲突时，以原始来源为准并标记冲突。
- 限流、缺字段或数据延迟时，降低结论置信度或停止量化判断，不用替代估计伪装成实时数据。
