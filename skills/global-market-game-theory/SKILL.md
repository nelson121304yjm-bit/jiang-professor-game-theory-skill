# 全球市场博弈论研判

把宏观政策、数据发布或新闻事件转化为可检验的美股与全球宏观研究判断：先确认事件和市场预期，再分析玩家互动，最后推导宏观变量、资产定价和条件式行动。结论的价值来自可被证伪的机制与触发点，而不是方向口号。

## 适用范围

适用于美股、全球宏观、美元、美债、黄金、原油及相关行业或指数的政策、数据和新闻驱动研究。开始前确认事件、分析时点、持有期（交易日/数周/数月）和资产范围；信息或时间窗口不清楚时，先说明限制。

## 新闻与数据核验

1. 获取最新资料时，使用配置的 API 和可追溯的实时来源并标记时区和截止时间；不要将训练数据当作当前新闻。
2. 优先使用央行、政府统计、公司公告、监管文件、交易所和财报电话会等一手资料。会影响市场的关键事实至少用两项独立来源交叉核验。
3. 分开写出“已证实事实、市场报道/观点、尚未证实信息、模型推断”。判断新闻冲击时，比较实际结果、市场共识和已计入价格的预期；没有共识或价格数据时不要假定“利多/利空”。

## 宏观政策与数据

政策层面优先读取政策原文，而非媒体转述：央行决议、会议纪要和官员讲话；财政预算、税收、关税、制裁与监管文件；以及官方发布日历。数据层面必须同时记录发布时点、实际值、前值、修正值、市场预期和统计口径。核心判断是“相对预期的变化”及其是否改变政策反应函数，不是单看数据绝对高低。

对每项新闻或数据，标记其状态：已经发布、预告、传闻、政策信号或市场解读。新闻 API 用于发现、去重和时间排序；涉及政策、数据或公司行动的关键结论，回溯至原文。没有配置的 API 文档或字段映射时，按 [数据源契约](references/source-contract.md) 提出所需字段，不猜测端点、认证方式或数据含义。

## 博弈论分析

使用已安装的 `players-incentives-constraints`、`escalation-exit` 和 `prediction-review` skills；未安装时，按其同名框架执行。识别关键玩家、激励、硬约束、信息不对称和对手反应，重点判断政策可信度、报复或让步空间、升级阈值和退出成本。把叙事压缩为不超过三个可观察机制。

## 宏观传导

对每个机制建立因果链：事件/策略互动 -> 增长、通胀、就业、财政或供给 -> 货币政策预期与金融条件 -> 企业盈利、估值折现率和风险偏好。区分即时交易冲击与中期基本面影响，指出链条中可能被政策、库存、汇率或替代供给打断的位置。

## 资产映射

至少覆盖受影响最大的两个资产桶：美股指数或行业、期限结构不同的美债、美元、黄金、能源/工业品；只有相关性和传导链充分时再加入信用、其他国家股市或加密资产。写清方向、时限、主要驱动变量和反向情景，避免把相关性当因果。

## 情景与行动框架

输出基准、上行和下行情景；概率是暂定主观权重，合计为 100%，并附每个情景的观察指标、失效条件和复盘日期。用“偏加仓、维持、降低风险、对冲、观望”表达研究层面的操作框架，同时说明何时不应行动。

操作建议必须受流动性、波动、集中度、仓位上限和止损/再评估点约束。没有用户的投资期限、风险承受力、持仓和地区/税务限制时，不给个体化仓位比例、具体交易指令或保证收益的说法；这不是个性化投资建议，也不执行交易。

## 输出

按 [报告模板](references/report-template.md) 交付。涉及私有 API 时只写来源名称、数据时间和字段口径，绝不输出密钥、完整认证头或私有端点。结尾列出最可能推翻结论的证据，以及下次需要重新判断的日期或数据发布节点。
