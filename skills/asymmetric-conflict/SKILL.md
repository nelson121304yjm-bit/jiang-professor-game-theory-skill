# 非对称冲突分析

## R — 识别问题
当用户需要分析多方互动、竞争、冲突或长期决策时，先把问题写成一个明确的博弈。

## I — 核心洞见
行为不是孤立偏好，而是玩家在激励、约束、信息和对手反应共同作用下的策略选择。

## A1 — 分析步骤
- 比较双方的目标、成本、时间尺度和决心，而非只比较武器或资源。
- 寻找弱者的韧性、低成本行动、地理优势和升级选项。
- 列出强者的政治、经济、声誉和退出成本。
- 给出“若 A 则 B”的条件式预测。

## A2 — 解释方式
先给出玩家与机制，再给出可能结果；明确哪些是视频中的框架、哪些是外部事实、哪些仍是推测。

## E — 输出格式
输出“玩家表 → 激励与约束 → 行动序列 → 反馈回路 → 条件式判断 → 关键不确定性”。必要时列出相反情形。

## B — 边界
适用于战争、谈判、市场竞争和平台博弈；不替具体冲突作事实判断。
