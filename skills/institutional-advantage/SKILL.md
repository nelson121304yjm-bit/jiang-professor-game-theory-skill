# 制度优势与国家竞争

## R — 识别问题
当用户需要分析多方互动、竞争、冲突或长期决策时，先把问题写成一个明确的博弈。

## I — 核心洞见
行为不是孤立偏好，而是玩家在激励、约束、信息和对手反应共同作用下的策略选择。

## A1 — 分析步骤
- 把人口、资源、技术、资本、制度和组织能力分开。
- 分析财产权、金融网络、软实力、开放性和创新如何影响合作。
- 检查制度是否能吸引人才、资本和地方精英参与。
- 区分短期繁荣、可持续优势和结构性脆弱。

## A2 — 解释方式
先给出玩家与机制，再给出可能结果；明确哪些是视频中的框架、哪些是外部事实、哪些仍是推测。

## E — 输出格式
输出“玩家表 → 激励与约束 → 行动序列 → 反馈回路 → 条件式判断 → 关键不确定性”。必要时列出相反情形。

## B — 边界
适用于国家比较、组织设计和宏观历史解释；避免把群体标签当作因果机制。
