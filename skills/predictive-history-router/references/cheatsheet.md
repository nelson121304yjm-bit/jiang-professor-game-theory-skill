# 决策规则速查 — Predictive History — Game Theory Series

| 能力 | 一句话规则 |
|---|---|
| 玩家—激励—约束分析 | 分析一项复杂事件中的参与者、目标、能力、约束与反馈回路。 |
| 非对称冲突分析 | 分析强弱双方为何可能出现与表面实力不一致的结果。 |
| 升级与退出成本 | 识别局部行动如何变成不可逆升级，并评估各方退出路径。 |
| 制度优势与国家竞争 | 比较一个国家或组织把人口、资本、技术和信念转化为长期优势的机制。 |
| 条件式预测与复盘 | 将宏大叙事转换为可检验的条件式预测，并在事后检查命中与失败。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
