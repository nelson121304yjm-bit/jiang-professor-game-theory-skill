# Predictive History Game Theory

Predictive History `Game Theory` series distilled into reusable Codex skills and a Chinese study note.

## Contents

- `skills/`: six focused analysis capabilities and a router for the series framework.
- `Predictive_History_江教授_博弈论系列学习笔记.docx`: Chinese notes covering the 30-episode playlist.

## Source

- Channel: https://www.youtube.com/@PredictiveHistory

## Scope

The skills distinguish the speaker's framework and assumptions from external facts and assistant inferences. They are intended for structured, conditional analysis rather than certainty or role-play as the presenter.
